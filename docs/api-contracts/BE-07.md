## Regla transversal + endpoints de pagos

Job Quartz crea `SubscriptionPayments` con `Status = PendingPayment` antes del vencimiento.

### Endpoints relacionados

| Operación | Método | Ruta | Auth | OperationId |
|-----------|--------|------|------|-------------|
| Listar pagos suscripción | GET | `/api/v1/subscription-payments` | SubscriptionPaymentAccess | `GetAllSubscriptionPayments` |
| Detalle pago | GET | `/api/v1/subscription-payments/{id}` | SubscriptionPaymentAccess | `GetSubscriptionPaymentById` |
| Subir voucher renovación | POST | `/api/v1/subscription-payments/{id}/voucher` | AccountOwner | `UploadRenewalVoucher` |

---

## POST `/api/v1/subscription-payments/{id}/voucher`

**Content-Type:** `multipart/form-data`

| Campo | Tipo | Requerido |
|-------|------|-----------|
| `voucherDate` | date-time | Sí |
| `voucher` | file | Sí |

### Response 200

```json
{
  "paymentId": "uuid",
  "status": "PendingApproval",
  "voucherUrl": "https://..."
}
```

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 404 | `SubscriptionPayment.NotFound` | id inexistente |
| 409 | `SubscriptionPayment.InvalidStatus` | no está en `PendingPayment` |
| 400 | `Validation.*` | archivo inválido |
