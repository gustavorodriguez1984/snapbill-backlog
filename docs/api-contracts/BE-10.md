## POST `/api/v1/invoices/{id}/payments`

```json
{
  "amount": 150.0,
  "paymentDate": "2026-05-29T10:00:00Z",
  "paymentMethod": "Transferencia",
  "reference": "TRX-001"
}
```

| `paymentMethod` | Valores |
|-----------------|---------|
| enum string | `Efectivo`, `TarjetaCredito`, `Cheque`, `Transferencia` |

### Response 201

```json
{
  "invoiceId": "uuid",
  "balanceDue": 50.0,
  "paidAmount": 150.0,
  "paymentStatus": "Partial",
  "paymentId": "uuid"
}
```

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 404 | `Invoice.NotFound` | factura inexistente |
| 409 | `Invoice.NotCredit` | factura contado |
| 409 | `Invoice.AlreadyPaid` | saldo cero |
| 409 | `Invoice.PaymentExceedsBalance` | monto > `balanceDue` |
| 400 | `Validation.*` | monto ≤ 0 |
