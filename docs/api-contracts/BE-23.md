## POST `/api/v1/supplier-returns`

```json
{
  "supplierId": "uuid",
  "warehouseId": "uuid",
  "coinId": "uuid",
  "returnDate": "2026-05-29T10:00:00Z",
  "notes": "Producto defectuoso",
  "payableAdjustment": {
    "supplierInvoiceId": "uuid",
    "amount": 200.0
  },
  "lines": [
    { "productId": "uuid", "quantity": 2, "unitCost": 80.0 }
  ]
}
```

- `payableAdjustment`: opcional — reduce CxP de factura proveedor.

### Response 201

Incluye `id`, `returnNumber`, líneas, ajuste CxP aplicado, stock actualizado (salida kardex).

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 409 | `WarehouseStock.Insufficient` | stock insuficiente |
| 409 | `SupplierReturn.PayableExceedsBalance` | ajuste > saldo factura |
