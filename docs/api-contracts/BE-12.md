## Flujo FE

1. `GET /api/v1/subscription-payments` → filtrar `status === "PendingPayment"`.
2. Usuario sube comprobante → `POST .../voucher` (multipart).
3. Estado pasa a `PendingApproval`.
4. PlatformAdmin aprueba en **BE-13**.
