## Campos en `CustomerDetailResponse`

```json
{
  "id": "uuid",
  "name": "Cliente SA",
  "creditLimit": 50000.0,
  "creditUsed": 12000.0,
  "creditAvailable": 38000.0,
  "priceListId": null
}
```

- `creditLimit`: `null` = sin tope.
- `creditUsed`: suma `balanceDue` facturas crédito abiertas.
- `creditAvailable`: `creditLimit - creditUsed` o `null`.

---

## POST `/api/v1/invoices` — validación

Si `paymentTerms === "Credito"` y `totalAmountBase + creditUsed > creditLimit`:

**409** `Customer.CreditLimitExceeded`
