## PATCH `/api/v1/products/{id}/deactivate`

**Auth:** JWT con rol `TenantAdmin` y `tenant_id`.

**Body:** ninguno.

### Response 204

Sin cuerpo.

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 404 | `Product.NotFound` | id no existe en tenant |
| 409 | `Product.AlreadyInactive` | ya inactivo |
| 403 | — | sin rol TenantAdmin |
