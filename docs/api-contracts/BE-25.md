## POST `/api/v1/quotes`

```json
{
  "customerId": "uuid",
  "coinId": "uuid",
  "quoteDate": "2026-05-29T10:00:00Z",
  "validUntil": "2026-06-29T10:00:00Z",
  "status": "Draft",
  "paymentTerms": "Contado",
  "lines": [
    { "productId": "uuid", "warehouseId": "uuid", "quantity": 2, "unitPriceBase": 100.0 }
  ]
}
```

| `status` | `Draft`, `Sent`, `Accepted`, `Rejected`, `Expired`, `Converted` |

### Response 201

Incluye `id`, `quoteNumber` (prefijo `COT`), totales, líneas.

---

## POST `/api/v1/quotes/{id}/convert-to-invoice`

**Body:** `{ "payments": [...] }` — misma forma que factura contado si aplica.

### Response 201

Factura creada (`CreateInvoiceResponse`). Cotización pasa a `Converted`.

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 409 | `Quote.Expired` | `validUntil` vencido |
| 409 | `Quote.AlreadyConverted` | ya convertida |
| 409 | `WarehouseStock.Insufficient` | sin stock al convertir |
