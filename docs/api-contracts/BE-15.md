## GET `/api/v1/customers/{id}/account-statement`

**Query**

| Parámetro | Tipo | Requerido |
|-----------|------|-----------|
| `from` | date (`YYYY-MM-DD`) | Sí |
| `to` | date | Sí |
| `format` | string | No — default `pdf` |

### Response 200

- **Content-Type:** `application/pdf`
- **Content-Disposition:** attachment `estado-cuenta-{from}-{to}.pdf`

Incluye facturas, abonos y NC del periodo en moneda base.

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 404 | `Customer.NotFound` | cliente |
| 400 | `Report.InvalidDateRange` | `to` < `from` |
| 400 | `Report.DateRangeTooLarge` | rango > 366 días |
