## GET `/api/v1/inventory/periods`

**Auth:** JWT con rol `TenantAdmin` o `TenantUser` y claim `tenant_id`.

**Query**

| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|-----------|-------------|
| `year` | `int` | Sí | Año fiscal calendario (2000–2100) |

### Response 200

```json
{
  "fiscalYearId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "year": 2026,
  "isClosed": false,
  "periods": [
    { "id": "3fa85f64-5717-4562-b3fc-2c963f66afa7", "month": 1, "isClosed": false },
    { "id": "3fa85f64-5717-4562-b3fc-2c963f66afa8", "month": 2, "isClosed": false }
  ]
}
```

- `periods` siempre incluye **12** entradas (`month` 1–12) cuando el año existe.
- Varios años/meses pueden tener `isClosed: false` al mismo tiempo (coexistencia).

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 400 | `FiscalYear.YearRequired` | falta query `year` |
| 400 | `FiscalYear.InvalidYear` | `year` fuera de 2000–2100 |
| 404 | `FiscalYear.NotFoundForYear` | el tenant no tiene ese año fiscal |
| 401 | — | sin JWT |
| 403 | — | sin rol tenant |

## Provisionamiento (sin endpoint)

| Evento | Comportamiento |
|--------|----------------|
| `POST /api/v1/tenants` (crear empresa) | Crea `FiscalYear` del año UTC actual + 12 `TenantPeriod` (`isClosed: false`). Idempotente. |
| Job Quartz (15 dic UTC) | Para cada tenant con suscripción `Active` o `Trial`, pre-crea el año **siguiente** + 12 meses. Idempotente. Config: `FiscalYearPreload:CronExpressionUtc` (default `0 0 0 15 12 ?`). |

## Verificación manual

1. AppHost + migración `AddFiscalYearAndTenantPeriod`.
2. Crear tenant → SSMS: `FiscalYears` + 12 filas en `TenantPeriods` para el año actual.
3. `GET /api/v1/inventory/periods?year=2026` con JWT tenant → 200 y 12 meses.

5. `GET` año inexistente → 404 `FiscalYear.NotFoundForYear`.
