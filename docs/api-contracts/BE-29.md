## GET `/api/v1/products/by-barcode/{barcode}`

- Trim automático del código escaneado.
- Response: `ProductDetailResponse` (200).

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 404 | `Product.NotFound` | barcode inexistente |
| 409 | `Product.Inactive` | producto desactivado (BE-27) |

---

## POST/PUT — campo `barcode`

- Nullable; trim al guardar.
- Validación: solo dígitos 8–14 (EAN/UPC) **o** alfanumérico hasta 50 chars.

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 400 | `Product.InvalidBarcode` | formato inválido |
| 409 | `Product.BarcodeAlreadyExists` | duplicado en tenant |
