## POST `/api/v1/supplier-invoices`

```json
{
  "supplierId": "uuid",
  "coinId": "uuid",
  "invoiceNumber": "FP-001",
  "invoiceDate": "2026-05-29T10:00:00Z",
  "totalAmount": 1500.0,
  "purchaseReceiptId": "uuid"
}
```

- `purchaseReceiptId`: opcional — vincula recepción existente.

### Response 201

```json
{
  "id": "uuid",
  "invoiceNumber": "FP-001",
  "totalAmount": 1500.0,
  "balanceDue": 1500.0,
  "paidAmount": 0.0
}
```

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 404 | `Supplier.NotFound` | — |
| 409 | `SupplierInvoice.AlreadyExists` | número duplicado |
