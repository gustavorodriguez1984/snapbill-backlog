## Regla transversal (job + guard)

Job `SubscriptionMoraProcessor` suspende cuentas con prefactura vencida.

### Efecto en API

Casi todos los endpoints de negocio (`TenantMember`) devuelven:

**HTTP 403**

```json
{
  "status": 403,
  "detail": "Subscription access denied.",
  "errorCode": "Subscription.AccessDenied"
}
```

Excepciones típicas: identity, subscription-payments (subir voucher), upgrade.

---

## GET `/api/v1/subscriptions/current`

Incluye flags de estado para mostrar pantalla de cuenta suspendida:

- `accountStatus`: puede ser `Suspended`
- `subscriptionStatus`, `nextBillingDate`, pagos pendientes
