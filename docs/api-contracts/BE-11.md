## Endpoints

| Operación | Método | Ruta | Auth | OperationId |
|-----------|--------|------|------|-------------|
| Crear NC | POST | `/api/v1/credit-notes` | TenantMember | `CreateCreditNote` |

| PDF térmico | GET | `/api/v1/credit-notes/{id}/print?format=pdf` | TenantMember | `PrintCreditNotePdf` |

---

## POST `/api/v1/credit-notes`

```json
{
  "invoiceId": "uuid",
  "creditNoteNumber": "NC-001",
  "creditNoteDate": "2026-05-29T12:00:00Z",
  "reason": "Devolución parcial",
  "lines": [
    { "invoiceDetailId": "uuid", "quantity": 1 }
  ]
}
```

### Response 201

```json
{
  "id": "uuid",
  "creditNoteNumber": "NC-001",
  "totalAmountBase": 100.0,
  "invoiceId": "uuid"
}
```

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 404 | `Invoice.NotFound` | factura origen |
| 409 | `CreditNote.QuantityExceedsInvoice` | cantidad > facturada |
| 409 | `CreditNote.InvoiceFullyCredited` | ya devuelto todo |
| 400 | `PeriodClosedOrNotConfigured` | período cerrado |

---

## Efectos

- Productos: kardex `Entrada`, incrementa stock.
- Factura crédito: reduce `balanceDue` hasta monto NC.
