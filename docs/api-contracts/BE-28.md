## GET `/api/v1/products/unit-of-measures`

### Response 200

```json
[
  { "code": "UND", "label": "Unidad" },
  { "code": "CAJ", "label": "Caja" },
  { "code": "KG", "label": "Kilogramo" },
  { "code": "LT", "label": "Litro" },
  { "code": "MT", "label": "Metro" },
  { "code": "PAR", "label": "Par" }
]
```

---

## POST/PUT producto

```json
{
  "unitOfMeasure": "CAJ"
}
```

- Default: `UND` si se omite.
- PDFs muestran cantidad + código (ej. `5 CAJ`).

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 400 | `Product.InvalidUnitOfMeasure` | código no permitido |
