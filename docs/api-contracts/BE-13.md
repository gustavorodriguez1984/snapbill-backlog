## Endpoints

| Operación | Método | Ruta | Auth | OperationId |
|-----------|--------|------|------|-------------|
| Aprobar renovación | PATCH | `/api/v1/subscription-payments/{id}/approve-renewal` | PlatformAdmin | `ApproveRenewalSubscriptionPayment` |
| Rechazar renovación | PATCH | `/api/v1/subscription-payments/{id}/reject` | PlatformAdmin | `RejectRenewalSubscriptionPayment` |
| Aprobar onboarding | PATCH | `/api/v1/subscription-payments/{id}/approve` | PlatformAdmin | `ApproveSubscriptionPayment` |

---

## PATCH `.../approve-renewal`

**Body:** ninguno.

### Response 204

Sin cuerpo. Extiende `NextBillingDate` y marca pago `Approved`.

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 404 | `SubscriptionPayment.NotFound` | — |
| 409 | `SubscriptionPayment.InvalidStatus` | no está `PendingApproval` |
| 403 | — | sin PlatformAdmin |

---

## PATCH `.../reject`

**Body (opcional):** `{ "reason": "..." }`

### Response 204

Pago vuelve a estado rechazado / requiere nuevo voucher según reglas.
