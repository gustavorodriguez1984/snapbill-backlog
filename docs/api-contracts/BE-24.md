## POST `/api/v1/price-lists`

```json
{
  "name": "Mayorista",
  "description": "Precios B2B",
  "isDefault": false,
  "isActive": true,
  "items": [
    { "productId": "uuid", "unitPriceBase": 95.0 }
  ]
}
```

### Response 201

`CreatePriceListResponse` con `id`, `name`, `isDefault`, items.

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 409 | `PriceList.DefaultAlreadyExists` | segunda lista default |
| 409 | `PriceList.HasCustomers` | delete con clientes asignados |
| 403 | — | CRUD write requiere TenantAdmin |

---

## Resolución en facturación

1. `Customers.priceListId` → precio item en lista.
2. Si null → lista `isDefault && isActive`.
3. Fallback → `Products.salePrice`.
4. Override manual `unitPriceBase`: solo **TenantAdmin**.
