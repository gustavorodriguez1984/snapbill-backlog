## POST `/api/v1/invoices` — crédito

**Body (fragmento relevante)**

```json
{
  "customerId": "uuid",
  "coinId": "uuid",
  "invoiceDate": "2026-05-29T12:00:00Z",
  "paymentTerms": "Credito",
  "lines": [
    {
      "productId": "uuid",
      "warehouseId": "uuid",
      "quantity": 2,
      "unitPriceBase": 100.0
    }
  ],
  "payments": []
}
```

- `paymentTerms`: `"Contado"` \| `"Credito"`.
- Crédito: **`payments` vacío** al emitir.
- Cliente debe tener `creditDays` configurado.

### Response 201 — campos CxC

```json
{
  "id": "uuid",
  "paymentTerms": "Credito",
  "totalAmountBase": 200.0,
  "balanceDue": 200.0,
  "paidAmount": 0.0,
  "paymentStatus": "Pending",
  "dueDate": "2026-06-28T12:00:00Z"
}
```

| `paymentStatus` | Significado |
|-----------------|-------------|
| `Pending` | sin abonos |
| `Partial` | abonos parciales (BE-10) |
| `Paid` | saldada |

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 409 | `Customer.CreditDaysRequired` | crédito sin días en cliente |
| 409 | `Customer.CreditLimitExceeded` | supera límite (BE-16) |
| 409 | `Product.Inactive` | producto inactivo (BE-27) |
| 400 | `PeriodClosedOrNotConfigured` | período cerrado (BE-02) |
