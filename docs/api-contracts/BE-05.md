## Regla transversal (sin endpoints nuevos de negocio)

Job Quartz `TrialLifecycleProcessor` gestiona el ciclo trial → `Expired` → `Inactive` tras gracia (30 días).

### Estados visibles para FE

| Campo / enum | Valores relevantes |
|--------------|-------------------|
| `SubscriptionStatus` | `Trial`, `Active`, `Expired`, `Inactive` |
| `AccountStatus` | incluye `Inactive` tras fin de gracia |
| `ExpiredAt`, `TrialRetentionEndsAt` | en suscripción actual (`GET /api/v1/subscriptions/current`) |

### Efecto en API

| Situación | HTTP | errorCode típico |
|-----------|------|------------------|
| Cuenta en mora/suspendida por SaaS (BE-14) | 403 | `Subscription.AccessDenied` |
| Trial expirado fuera de gracia | login/operaciones según guard | — |

---

## GET `/api/v1/subscriptions/current` *(referencia)*

**Auth:** `AccountOwner` o `TenantMember`.

Response incluye estado de suscripción y fechas trial. FE debe mostrar banner/redirect si `Expired` o `Inactive`.
