## Query params comunes

| Parámetro | Tipo | Requerido | Default | Descripción |
|-----------|------|-----------|---------|-------------|
| `fromDate` | date | según reporte | inicio mes actual | Fecha inicial |
| `toDate` | date | según reporte | fin mes actual | Fecha final |
| `warehouseId` | Guid | solo reportes de bodega | | Filtro de bodega |
| `productId` | Guid | solo reportes de producto | | Filtro de producto |
| `categoryId` | Guid | solo reportes de categoría | | Filtro de categoría |
| `customerId` | Guid | solo reportes de cliente | | Filtro de cliente |
| `supplierId` | Guid | solo reportes de proveedor | | Filtro de proveedor |

## Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 403 | `Auth.Forbidden` | Usuario sin rol requerido |
| 403 | `Subscription.ReportNotAvailable` | Reporte no habilitado en el plan actual |
| 400 | `Validation.InvalidDateRange` | `fromDate` > `toDate` |
| 404 | `Customer.NotFound` | `customerId` inexistente |
| 404 | `Supplier.NotFound` | `supplierId` inexistente |
| 404 | `Product.NotFound` | `productId` inexistente |
| 404 | `Warehouse.NotFound` | `warehouseId` inexistente |
| 404 | `Category.NotFound` | `categoryId` inexistente |

## Notas FE

- Consumir `GET /api/v1/reports/available` para armar el menú de reportes.
- Mostrar reportes deshabilitados bloqueados con badge del plan requerido (upsell).
- Todos los endpoints devuelven PDF (`application/pdf`).
- Los filtros se envían como query params; las rutas con `{id}` son path params.
- Fechas en formato ISO 8601 (`yyyy-MM-dd`).

---

## Notas BE

- Respetar `TenantId` global query filter en todas las consultas.
- Validar entitlement mediante `ISubscriptionEntitlementService` + políticas de autorización.
- Los reportes auxiliares de ventas/compras **no son formato DGI**; son listados detallados para el contador.
- El reporte de compras (`purchases`) debe incluir: órdenes de compra, recepciones y facturas de proveedor.
