## POST `/api/v1/subscriptions/upgrade-from-trial`

**Content-Type:** `multipart/form-data`

| Campo | Tipo | Requerido |
|-------|------|-----------|
| `subscriptionTypeId` | UUID | Sí |
| `billingCycle` | string enum | Sí — `Monthly`, `Quarterly`, `Semiannual`, `Annual` |
| `voucherDate` | date-time ISO | Sí |
| `voucher` | file | Sí — PDF/JPEG/PNG, máx. 1 MB |

### Response 201

Misma forma que onboarding (`OnboardingSubscriptionResponse`): `subscriptionId`, `paymentId`, `status` (`PendingApproval`), etc.

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 400 | `Validation.*` | campos inválidos o archivo no permitido |
| 409 | `Subscription.NotTrial` | la suscripción actual no está en trial |
| 409 | `Subscription.AlreadyActive` | ya tiene plan de pago activo |
| 403 | — | sin rol AccountOwner |
