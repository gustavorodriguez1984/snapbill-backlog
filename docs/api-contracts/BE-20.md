## POST `/api/v1/inventory-adjustments`

```json
{
  "warehouseId": "uuid",
  "adjustmentDate": "2026-05-29T10:00:00Z",
  "reason": "Conteo físico",
  "lines": [
    { "productId": "uuid", "quantity": -3 },
    { "productId": "uuid", "quantity": 2 }
  ]
}
```

- `quantity` positivo = entrada, negativo = salida.

### Response 201

Incluye `id`, `adjustmentNumber`, líneas con stock actualizado.

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 409 | `WarehouseStock.Insufficient` | salida deja stock negativo |
| 403 | — | requiere TenantAdmin |
