## GET `/api/v1/reports/profit-margin`

**Query**

| Parámetro | Tipo | Requerido |
|-----------|------|-----------|
| `from` | date | Sí |
| `to` | date | Sí |
| `groupBy` | string | No — `Product` (default) \| `Category` |

### Response 200

```json
{
  "from": "2026-01-01",
  "to": "2026-01-31",
  "groupBy": "Product",
  "totals": {
    "quantity": 10,
    "salesAmount": 1000.0,
    "costAmount": 800.0,
    "profitAmount": 200.0,
    "marginPercentage": 20.0
  },
  "lines": [
    {
      "productId": "uuid",
      "categoryId": "uuid",
      "name": "Widget",
      "sku": "SKU-1",
      "quantity": 10,
      "salesAmount": 1000.0,
      "costAmount": 800.0,
      "profitAmount": 200.0,
      "marginPercentage": 20.0
    }
  ]
}
```

- Costo desde kardex `Salida`; NC del periodo restan ventas y costo.

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 403 | `Subscription.ReportNotAvailable` | plan sin reporte |
| 400 | `Report.InvalidDateRange` | `to` < `from` |
| 400 | `Report.DateRangeTooLarge` | > 366 días |
