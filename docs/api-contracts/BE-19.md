## Endpoints

| Operación | Método | Ruta | Auth | OperationId |
|-----------|--------|------|------|-------------|
| Listar transferencias | GET | `/api/v1/warehouse-transfers` | TenantMember | `GetAllWarehouseTransfers` |
| Crear transferencia | POST | `/api/v1/warehouse-transfers` | TenantMember | `CreateWarehouseTransfer` |

---

## POST `/api/v1/warehouse-transfers`

```json
{
  "sourceWarehouseId": "uuid",
  "destinationWarehouseId": "uuid",
  "transferDate": "2026-05-29T10:00:00Z",
  "notes": "Reabastecimiento",
  "lines": [
    { "productId": "uuid", "quantity": 5 }
  ]
}
```

### Response 201

```json
{
  "id": "uuid",
  "transferNumber": "TRF-001",
  "sourceWarehouseId": "uuid",
  "destinationWarehouseId": "uuid",
  "lines": [
    { "productId": "uuid", "quantity": 5, "updatedSourceStock": 15, "updatedDestinationStock": 20 }
  ]
}
```

### Errores

| HTTP | errorCode | Cuándo |
|------|-----------|--------|
| 409 | `WarehouseTransfer.SameWarehouse` | origen = destino |
| 409 | `WarehouseStock.Insufficient` | stock insuficiente en origen |
| 404 | `Warehouse.NotFound` | bodega inválida |
