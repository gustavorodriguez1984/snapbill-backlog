## POST `/api/v1/supplier-invoices/{id}/payments`

```json
{
  "amount": 500.0,
  "paymentDate": "2026-05-29T10:00:00Z",
  "paymentMethod": "Transferencia",
  "reference": "OP-123"
}
```

### Response 201

Actualiza `balanceDue`, `paidAmount` de la factura proveedor.
